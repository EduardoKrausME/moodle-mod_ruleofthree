# mod_ruleofthree

Atividade Moodle para explorar regra de três de forma interativa.

## Modos

- Regra de três simples, direta ou inversa, com quatro campos sincronizados.
- Regra de três composta, com duas grandezas de influência e um resultado em duas situações.
- Alteração instantânea dos valores sem recarregar a página.
- Passo a passo da equação, substituição e resultado.
- Sem armazenamento de respostas do estudante.

## Requisitos

Moodle 4.5 ou superior.
